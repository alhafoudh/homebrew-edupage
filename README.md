# alhafoudh/edupage

Homebrew tap for [edupage-cli](https://github.com/alhafoudh/edupage-cli), a read-only
Ruby library, CLI, REST API and MCP server for Edupage.

```bash
brew install alhafoudh/edupage/edupage-cli
```

Works with Homebrew on macOS and on Linux. The formula builds from the tagged source
with Homebrew's Ruby and keeps its gems private to the formula; the first install
compiles a couple of native gems, so it takes about a minute.

The formula is bumped automatically by the release workflow in edupage-cli whenever a
new version is published.
